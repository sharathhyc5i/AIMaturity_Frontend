# Logo slots

Drop official logo files here and the app picks them up automatically — no code change needed.
Until a file exists, the app shows the name in plain type.

| File name                | Used for                                  |
|--------------------------|-------------------------------------------|
| `microsoft.svg` / `.png` | Header (left) and the intro screen        |
| `best-buy.svg`           | Retailer logo (header right, intro, accounts) |
| `currys.svg`             | 〃 |
| `yodobashi.svg`          | 〃 |
| `jb-hi-fi.svg`           | 〃 |
| `ingram-micro.svg`       | 〃 |

SVG is tried first, then PNG. Use the brand files your organisation is licensed to use;
none are bundled with this project.
